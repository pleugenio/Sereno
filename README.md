# Sereno

Protótipo local de uma plataforma de gestão para profissionais de Psicologia. A primeira versão é focada em agenda administrativa, pacientes e controle financeiro básico, sem prontuário ou dados clínicos.

## Executar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite, normalmente `http://localhost:5173`.

## Validar a versão de produção

```bash
npm run build
npm run preview
```

Todos os nomes e dados incluídos no protótipo são fictícios. Novos atendimentos ficam armazenados somente no navegador por meio de `localStorage`.
